## 🌟 为什么诞生 Antigravity-PM？

传统的看板工具（如 Jira、Trello）无法理解**智能体专家团队、技能挂载矩阵、自动化回测管线与动态工程锁**。

**Antigravity-PM** 专为连接 **人类工程师** 与 **Antigravity 多智能体生态** 而设计，贯彻开源共享与互联网极客精神，让每一位开发者都能**零门槛可视化管理自己的多智能体项目、自由配置垂直专家团队，并随时插拔底层 Skill 自动化技能插件**！

## ⚡ 核心功能与亮点介绍 (Key Features)

### 1. 🧩 垂直专家团与底层 Skill 可视化全景中心
- **自由自定义专家团**：用户可任意创建、重命名、配置专家角色名录、领域评级与职责；
- **底层 Skill 插件无缝插拔**：规范采用 `英文名称（中文名称）` 并提供 1-5 星领域打分，可自由挂载/卸载；
- **双视图模式切换**：支持 **🗂️ 大卡片沉浸式展开视图** 与 **📋 高信息密度文本条目紧凑视图**，无论生态多大，均可平滑顺畅下滑到底。

### 2. 📊 严谨的多项目生命周期与双轨指标隔离
- **研发看板流 (Kanban)**：支持策略筹备 (Backlog)、规划设计 (Planning)、仿真测试 (Testing)、实盘生产 (Live) 全流程拖拽流转；
- **量化策略与通用项目智能隔离**：只有金融量化策略才会显示夏普比率、最大回撤、年化收益率等硬核指标；小游戏、PPT、官网网页、文案创作等非量化项目干净清爽，绝不产生指标污染。

### 3. 🤖 Antigravity IDE 双向实时联动与修改工坊
- **双向无缝互联**：支持一键从看板唤醒 Antigravity IDE 定位工作区，双向实时同步项目进度与任务状态；
- **全自动生态修改工坊**：在客户端点击 **`💡 在 IDE 中编辑生态配置`**，系统会自动以结构化 Markdown 形式导出全景专家团与技能清单，并在 IDE 中主动询问用户修改需求，实现配置全自动重构并热同步回桌面客户端。

### 4. ⚙️ PM2 工业级进程守护与控制台双轨日志
- **进程高可用网关**：内置 PM2 进程网关管理，支持策略后台常驻挂机、奔溃自愈重启与状态实时监控；
- **双轨日志抽屉**：既能实时滚动查看 PM2 控制台标准输出，又能读取并渲染微信气泡式的 Antigravity IDE 真实历史对话与专家协同流水。

### 5. 🛡️ 钱学森工程控制论级抗脆弱性
- 内置 **PID + 时间戳 + 高熵随机数文件原子防撞锁**，经受 100 次并发密集读写碰撞 0 错误；
- 单实例锁（Single Instance Lock）保障客户端多开防撞，全局零死锁、零内存泄漏。

## 🚀 快速上手与运行 (Quick Start)

### 方式 A：免配置直接运行 (Portable 绿色免安装版)
若您只想快速使用桌面客户端，可在 [Releases](../../releases) 页面下载绿色免安装包：
- **`Antigravity-PM-Pure-Portable.zip`** (纯净无预设版 · 推荐)
- **`Antigravity-PM-Full-Portable.zip`** (完整全功能版)

解压后双击 `Antigravity-PM.exe` 即可直接启动！

### 方式 B：从源码启动与开发
```bash
# 1. 克隆本仓库 (默认纯净版)
git clone https://github.com/MUMUMU23333/Antigravity-PM.git
cd Antigravity-PM

# 2. 安装项目依赖
npm install

# 3. 启动前端 Vite 调试服务
npm run dev

# 4. 启动 Electron 桌面应用 (支持前后端热重载)
npm run electron:dev

# 或者在 Windows 上直接双击运行：
run.bat
```

## 📦 版本演进与历史归档机制 (Versioning & Archive Policy)

本项目严格遵循 **语义化版本规范 (SemVer)** 与 **历史旧版本归档留痕机制**：

```text
Antigravity-PM/
├── 📄 CHANGELOG.md                     # 当前最新版本更新日志（聚焦最新纯净版 v1.1.0）
├── 📂 presets/                         # 官方生态预设包目录
│   └── 📄 official-full-preset.json   # 官方完整版预设包（可一键载入）
└── 📂 docs/
    └── 📂 history/                     # 历史版本永久归档目录（旧版本自动沉淀于此）
        ├── 📄 v1.0.0-full-edition.md   # [旧版归档] v1.0.0 完整版全景档案与指标记录
        └── 📄 v1.1.0-pure-edition.md   # [最新发布] v1.1.0 纯净版轻量通用框架发行报告
```

每当系统发布新的版本时，旧版本的里程碑说明、架构设计与构建产物自动归档至 `docs/history/` 目录中，确保新版本轻快明了，旧版本历史永不丢失！
