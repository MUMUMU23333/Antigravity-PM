## 🌟 为什么诞生 Antigravity-PM？

在 AI 大模型与自主智能体（Autonomous Agents）爆发的当下，传统的项目看板工具（如 Jira、Trello 等）仅能管理人类任务，**无法理解智能体专家团队、技能挂载矩阵、自动化回测管线与动态工程锁**。

**Antigravity-PM** 专为连接 **人类工程师** 与 **Antigravity 多智能体生态** 而设计，贯彻开源共享与互联网极客精神，让每一位开发者都能**零门槛可视化管理自己的多智能体项目、自由配置垂直专家团队，并随时插拔底层 Skill 自动化技能插件**！

## ⚡ 核心功能与亮点介绍 (Key Features)

### 1. 🧩 垂直专家团与底层 Skill 可视化全景中心
- **全域九大垂直专家决策团**：涵盖股票投研实战圆桌、多空量化决策组、钱学森工程控制论总工守门员、全语言工业级代码审查官、独立游戏工坊、现代网页体验架构师、本地隐私数据分析团、人感演示PPT等 9 大领域；
- **底层 Skill 插件无缝挂载**：内置 18+ 款工业级技能（全市场行情财报穿透、多因子选股、抗过拟合雷达、Canvas打击感动效引擎、Web Audio音频合成、TDD原子工程总线等），规范采用 `英文名称（中文名称）` 并提供 1-5 星领域评分；
- **双视图模式切换**：支持 **🗂️ 大卡片沉浸式展开视图** 与 **📋 高信息密度文本条目紧凑视图**，无论生态多大，均可平滑顺畅下滑到底、完整对比所有专家角色与职责。

### 2. 📊 严谨的多项目生命周期与双轨指标隔离
- **研发看板流 (Kanban)**：支持策略筹备 (Backlog)、规划设计 (Planning)、仿真测试 (Testing)、实盘生产 (Live) 全流程拖拽流转；
- **量化策略与通用项目智能隔离**：只有金融量化策略才会显示夏普比率、最大回撤、年化收益率等硬核指标；小游戏、PPT、官网网页、文案创作等非量化项目干净清爽，绝不产生指标污染。

### 3. 🤖 Antigravity IDE 双向实时联动与修改工坊
- **双向无缝互联**：支持一键从看板唤醒 Antigravity IDE 定位工作区，双向实时同步项目进度与任务状态；
- **全自动生态修改工坊**：在客户端点击 **`💡 在 IDE 中编辑生态配置`**，系统会自动以结构化 Markdown 形式导出全景专家团与技能清单，并在 IDE 中主动询问用户修改需求，实现配置全自动重构并热同步回桌面客户端。

### 4. ⚙️ PM2 工业级进程守护与控制台双轨日志
- **进程高可用网关**：内置 PM2 进程网关管理，支持策略后台常驻挂机、奔溃自愈重启与状态实时监控；
- **双轨日志抽屉**：既能实时滚动查看 PM2 控制台标准输出，又能读取并渲染微信气泡式的 Antigravity IDE 真实历史对话与专家协同流水。

### 5. 🛡️ 钱学森工程控制论级抗脆弱性
- 内置 **PID + 时间戳 + 高熵随机数文件原子防撞锁**，经受 100 次并发密集读写碰撞 0 错误；
- 单实例锁（Single Instance Lock）保障客户端多开防撞，全局零死锁、零内存泄漏。

## 🚀 快速上手与运行 (Quick Start)

### 方式 A：免配置直接运行 (Portable)
若您只想快速使用桌面客户端，可在 [Releases](../../releases) 页面下载绿色免安装包，解压后双击 `Antigravity-PM.exe` 即可直接使用！

### 方式 B：从源码启动与开发
```bash
# 1. 克隆本仓库
git clone https://github.com/MUMUMU23333/Antigravity-PM.git
cd Antigravity-PM

# 2. 安装项目依赖
npm install

# 3. 启动前端 Vite 调试服务
npm run dev

# 4. 启动 Electron 桌面应用 (支持前后端热重载)
npm run electron:dev

# 或者在 Windows 上直接双击运行：
run.bat
```

### 方式 C：构建桌面安装包
```bash
npm run electron:pack
# 或直接双击 pack.bat
```

## 📦 版本演进与历史归档机制 (Versioning & Archive Policy)

为了保障项目的长久可追溯性与稳定性，Antigravity-PM 遵循 **语义化版本规范 (SemVer)** 与 **旧版本自动归档留痕机制**：

- 📝 **当前最新发布日志**：统一记录于项目根目录的 [`CHANGELOG.md`](./CHANGELOG.md)；
- 📂 **历史旧版本归档库**：当系统发布新的版本时，旧版本的里程碑说明、构建产物与发布纪要将自动归档至 [`docs/history/`](./docs/history/) 目录（例如 `docs/history/v1.0.0-release.md`），确保版本资产永不丢失、新旧并存随时可查！
