# 📦 Antigravity-PM 历史版本发布归档：v1.0.0

- **发布日期**: 2026-09-05
- **Git Commit**: Initial Release
- **构建状态**: 100% 通过 50路并发读取压测、100次微秒级写碰撞测试与模糊安全测试
- **兼容环境**: Windows 10/11 x64, macOS, Linux, Node.js 18+, Electron 34+

---

## 🌟 版本详细记录

### 1. 核心业务层
- 完成从个人环境向通用跨平台开源工程的深度脱敏与重构；
- 剥离所有写死的私有路径，全面支持基于 `os.homedir()` 的跨系统自适应探测；
- 默认提供标准开箱即用的 4 大核心领域示范项目（量化趋势策略、赛博朋克肉鸽小游戏、Bento 极简官网、本地数据挖掘）。

### 2. 交互与可视化层
- 在“技能与专家团中心”新增了双视图切换机制（卡片视图 / 紧凑文本条目视图）；
- 全面解除了视窗垂直滚动的限制，支持高密度信息平滑滑至底部；
- 优化了弹窗布局与弹性排版，彻底消除了按钮遮挡与文本截断。

### 3. 系统抗扰与工程控制论层
- 钱学森系统总工守门员把关：时滞抗扰、负反馈防自激震荡、资源枯竭兜底；
- `ideSync.cjs` 增加 `process.pid + Date.now() + 6位高熵随机数` 原子锁；
- `get_ide_logs.py` 增加 NUL 字节防御与顶层安全捕获。
