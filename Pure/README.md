# Antigravity-PM · 纯净版 (Pure Clean Edition)

> 🚀 **零预装、极简轻量、开箱即用的 Antigravity 可视化项目与专家团调度母版**

---

## 🌟 纯净版定位
纯净版移除了所有特定的演示量化策略与内置数据包，为您保留纯净的标准程序骨架。特别适合：
- 希望从零搭建自己私有业务/量化/研发看板的用户；
- 想要完全自主配置专属专家团队与自动化 Skills 的团队；
- 作为企业内部或二次分发的干净母版。

## ⚡ 极速启动 (2 种方式)

### 方式 A：双击即用 (推荐)
已内置开箱即用的前端生产包 `dist/`：
1. 确保本机已安装 [Node.js (v18+)](https://nodejs.org/)；
2. 双击运行 `run.bat`，即可自动启动可视化客户端！

### 方式 B：开发者模式
```bash
# 1. 安装依赖
npm install

# 2. 启动前端 Vite 实时开发服务
npm run dev

# 3. 启动桌面客户端
npm run electron:dev
```

## 🛠️ 最新修复与特性
- 💬 **对话记录鼠标滚轮平滑滚动**：支持向上自由滚动查看完整上下文，且智能暂停吸底；
- ⬇️ **一键吸底切换**：支持点击「⬇️ 跳到最新对话」或底部状态栏一键恢复自动滚屏；
- 🖥️ **PM2 进程托管与一键自愈**：全生命周期守护后台脚本。
